⚙ Workshop Manager
ゲーム

    引数を指定すると、起動時に Steam が確認ダイアログを表示します。

    Steam API の仕組み上、接続中は Steam 上でそのゲームが「実行中（プレイ中）」になります。 そのため普段は接続せず、購読・更新・検索などの操作をするときだけ接続し、終わったら約 15 秒で切断します。 購読状態と更新の有無は Steam の記録ファイルから読むので、接続しなくても表示されます。

    Steam の「ローカルで無効化」とロード順の仕組みに対応したゲームで反映されます。

    現在の有効/無効とロード順を名前を付けて保存し、いつでも切り替えられます。

      共有

      プロファイルをファイルや共有コードにしてフレンドに渡せます。読み込んだ側で足りない MOD は、まとめて購読できます。

      と、有効/無効を同期します（並べ替えたことがある場合はロード順も同期します）。 ゲームの実行中に変更したときは、ゲームの終了後に反映します。書き込む前に設定ファイルのバックアップ（.wsm-backup）を作ります。

      有効なMODをゲームのMODフォルダへ配置します（ジャンクションなら容量を消費しません）。再デプロイ時は本ツールが配置したものだけを入れ替えます。

      MODリストを共有・バックアップできます。

      コレクション照合

      ワークショップのコレクションURLかIDを入力すると、未購読のアイテムを確認できます。
